# Dashboard interactivo para la gestión de eventos científicos — Demo de portafolio

[Ver el archivo HTML](index.html)

Esta carpeta contiene una demostración independiente de un panel de gestión académica, editorial y financiera para eventos científicos. Es un proyecto de ingeniería de software presentado **con información sintética**.

## Características ilustradas
- Indicadores y gráficos de resumen.
- Consultas y filtros por modalidades, ejes, perfiles e instituciones.
- Seguimiento de estados de pagos y trabajos académicos.
- Tablas de detalle y visualizaciones interactivas.

## Privacidad y alcance
- Los 34 registros son completamente **ficticios**.
- Este HTML no se conecta a ninguna matriz institucional ni a Google Apps Script.
- No incluye identificadores reales de Google Sheets ni logotipos institucionales.
- Los resultados mostrados son demostrativos: no constituyen evidencia científica de desempeño real.
